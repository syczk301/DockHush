隐坞 DockHush / Installation

将 DockHush.app 拖入 Applications（应用程序），弹出磁盘映像，再从“应用程序”打开。
Drag DockHush.app into Applications, eject the disk image, then launch it from Applications.

此版本为本地临时签名构建，尚无 Apple Developer ID 签名或公证。
macOS 可能阻止首次打开。确认下载来源后，请自行在“系统设置 → 隐私与安全性”中检查并允许打开，或选择从源码构建。不要关闭 Gatekeeper 或 SIP。
This build is ad-hoc signed, without Apple Developer ID signing or notarization.
macOS may block first launch. After verifying the source, review the app in System Settings → Privacy & Security, or build it yourself. Do not disable Gatekeeper or SIP.

主窗口右上角齿轮可切换：跟随系统、简体中文、English。
Choose System Default, 简体中文 or English from the gear button.

关闭时隐藏需要“辅助功能”权限。部分 Dock 设置需要“App 管理”权限。
只开启你需要的功能。DockHush 首次运行不会自动管理任何第三方应用。
Hide on Close requires Accessibility. Some Dock settings require App Management.
Only enable features you need. No third-party apps are managed by default.

显示 Dock 图标：开启显示，关闭隐藏。部分应用需重启；请先保存工作。
Show in Dock: on shows the icon, off hides it. Some apps restart; save your work first.

极空间的可选运行时适配需要 Node.js 22+，且会在启用前单独询问。
The optional ZSpace runtime integration requires Node.js 22+ and asks before activation.

酷狗音乐 Dock 适配支持 20.3.8（3898），隐藏时需正常重启，会中断播放；隐藏后请通过 DockHush 打开窗口。其他启动器可能恢复图标。此适配不修改酷狗文件或签名，但依赖 macOS 非公开接口，系统更新后可能失效。
Kugou Dock support targets 20.3.8 (3898). Hiding requires a normal restart and interrupts playback. Reopen through DockHush; other launchers may restore the icon. Kugou files and signatures remain unchanged, but this uses a private macOS interface that may break after updates.
