# 隐坞 DockHush v0.2.0

新增酷狗音乐适配，并将本次源码、应用版本和 DMG 对齐到 `v0.2.0` 标签。

- 酷狗关闭按钮：兼容 Mac Catalyst 缺少辅助功能子角色的情况，精确核对关闭按钮位置与大小；不拦截相邻窗口按钮。
- 酷狗 Dock 图标：支持 20.3.8（3898），验证厂商签名后使用运行时启动选项，不修改安装包或签名。隐藏需正常退出并重启，会中断播放；恢复显示无需重启。
- 隐藏后通过 DockHush 的“打开应用”恢复窗口。其他启动器可能使图标重新出现。适配使用 macOS 非公开接口，系统更新后可能失效。
- 包含 v0.1.0 标签之后的 TempoHub 保留签名运行时适配及极空间开关直接接管修复。
- 新增酷狗回归检查、双语说明和统一的 `VERSION` 文件；DMG 打包会核对应用版本，避免版本号不一致。

验证：Apple Silicon / macOS 26 / 酷狗 20.3.8（3898）已验证实体关闭按钮、窗口恢复、正常退出、Dock 隐藏与恢复显示。厂商文件哈希未变化，原签名严格校验通过。构建包含 arm64 与 x86_64；Intel、较旧 macOS 和播放中的音频连续性未实测。

下载 `DockHush-0.2.0-universal.dmg`，将应用拖入 Applications。安装包为临时签名，未使用 Apple Developer ID 签名或公证。升级后可能需要重新添加辅助功能权限。完整安装、兼容性和恢复说明见仓库 README。

```sh
shasum -a 256 -c DockHush-0.2.0-universal.dmg.sha256
```

## English

Adds Kugou Music support, with source, app metadata and DMG version aligned to tag `v0.2.0`.

- Recognizes the exact Catalyst close button when its Accessibility subrole is missing, while leaving adjacent controls alone.
- Controls the Dock icon for Kugou 20.3.8 (3898) without modifying its bundle or vendor signature. Hiding requires a normal restart and interrupts playback; showing takes effect without restarting.
- Reopen hidden windows through DockHush. Other launchers may restore the icon. This integration uses a private macOS launch interface that may break after system updates.
- Includes the signature-preserving TempoHub runtime integration and direct ZSpace integration fix added since the v0.1.0 tag.
- Adds Kugou regression checks, bilingual documentation and a shared `VERSION` file. Packaging rejects a mismatched app version.

Runtime validation: Apple Silicon / macOS 26 / Kugou 20.3.8 (3898), including a physical close-button click, reopening, normal exit and Dock visibility changes. Vendor hashes and strict signature verification passed. Universal arm64/x86_64 build; Intel hardware, older macOS and audio playback continuity remain untested.

The DMG is ad-hoc signed, without Developer ID signing or notarization. Updated apps may need their Accessibility permission entry refreshed. See README for installation, compatibility and recovery details.
