# DockHush 官网

网址：https://syczk301.github.io/DockHush/

网页源文件：index.html、style.css、app.js、assets/。修改后推送 main 会触发 .github/workflows/website.yml，构建并发布到 GitHub Pages。

本地构建：`python3 website/build.py`；本地预览：`python3 -m http.server --directory _site 8000`。

下载链接指向各项目已公开发布的 DMG。更新软件后，请同步版本号和下载链接。网页交互仅作示意，不会控制本机应用。
