# 隐坞 DockHush

**应用继续运行，桌面少些打扰。**

[English](README.en.md) · [下载 DMG](https://github.com/syczk301/DockHush/releases/latest) · [MIT 许可证](LICENSE)

macOS 菜单栏工具，分别控制应用的关闭行为与 Dock 图标。原生 SwiftUI / AppKit 实现，无账号、无遥测。

## 功能

- 自动扫描已安装与正在运行的应用，搜索、筛选，并可隐藏系统应用条目。
- **关闭时隐藏**：拦截受支持应用的红色关闭按钮，隐藏窗口并保持运行；⌘Q 仍可退出。
- **显示 Dock 图标**：开启显示，关闭隐藏；助手自身也在列表中。
- 主窗口、菜单、提示支持**跟随系统 / 简体中文 / English**，即时切换并保存。
- 部分 Dock 修改需重启应用：先备份，失败自动还原；检测到其他修改时停止覆盖。

## 安装

1. 在 [Releases](https://github.com/syczk301/DockHush/releases) 下载 `DockHush-0.1.0-universal.dmg`。
2. 打开磁盘映像，将 `DockHush.app` 拖入 `Applications`，弹出映像后启动应用。
3. 按需授权：**辅助功能**用于关闭时隐藏；**App 管理**用于修改部分第三方应用配置。这两项是系统级权限，请按实际需要开启。
4. 首次运行不预选第三方应用。按需设置列表中的两个开关。

构建面向 **macOS 13+、Apple Silicon 与 Intel**。本次本机运行验证为 Apple Silicon / macOS 26；Intel 与较旧 macOS 仅完成交叉编译，尚未实机验证。

当前 DMG 使用临时签名，**没有 Apple Developer ID 签名或公证**。macOS 可能阻止首次启动；确认来源后，请自行在“系统设置 → 隐私与安全性”检查并允许打开，或从源码构建。不要关闭 Gatekeeper 或 SIP。应用更新或自行重新编译后，可能需要移除并重新添加原有权限记录。

希望登录时启动，可将安装后的应用添加到“系统设置 → 通用 → 登录项与扩展 → 登录时打开”。

## 使用与限制

右上角齿轮切换语言、打开权限设置和备份文件夹；列表右键可打开应用或隐藏窗口。底部“查看详情”显示完整操作结果。

| 控制项 | 开启 | 关闭 |
| --- | --- | --- |
| 关闭时隐藏 | 点击关闭按钮时隐藏应用 | 交由应用自身处理关闭 |
| 显示 Dock 图标 | 显示图标 | 隐藏图标 |
| 隐藏系统应用 | 从列表过滤系统应用 | 在列表中显示系统应用 |

“关闭时隐藏”通常隐藏整个应用，包括它的多个窗口。通用拦截依赖应用暴露的辅助功能关闭按钮；自绘按钮不保证支持。TempoHub 包含坐标识别逻辑，其界面布局变化可能影响识别。

对普通第三方应用，Dock 控制修改 `Contents/Info.plist` 的 `LSUIElement`，因此需要正常退出并重启目标应用。**修改签名包内的配置可能导致原签名校验失败**；本工具不会重新签名第三方应用，也不保证所有应用都支持。系统受保护、不可写或配置为软链接的应用不会修改。执行前保存工作；退出超时会取消操作，不强制结束普通应用。

验证包含应用存活与 Dock 激活类型；成功只表示本次检查通过。后续应用自行改变状态、升级或外部编辑仍可能使设置失效。检测到更新或冲突时，工具保留备份并停止覆盖，不自动覆盖新版本。

### TempoHub 运行时适配

已验证 TempoHub 1.3.0 / Qt 6.7（Apple Silicon）：通过 Qt 的可选外置扩展入口，在进程内切换 Dock 状态，不修改 `Info.plist`、可执行文件或厂商签名，也不开放调试端口。首次隐藏需确认正常退出并通过 DockHush 重新打开；加载后显示/隐藏开关直接生效。“关闭时隐藏”仍独立由辅助功能实现。完全退出 TempoHub 后，需要通过 DockHush 再次打开才能加载适配；从访达普通启动始终使用原厂应用。

启用前验证厂商签名和 Qt 插件版本；不支持的更新会安全停止，加载失败尝试恢复普通启动。旧式配置修改及备份回写持续被禁止。外置组件副本和会话记录保存在 `~/Library/Application Support/DockHush/TempoRuntime/`、`tempo-session.json`。

### 极空间（可选）

仅针对安装在 `/Applications/极空间.app` 的桌面客户端。需要 **Node.js 22+**，支持 Homebrew 常见路径和进程 PATH。其他功能不依赖 Node.js。

在列表切换极空间的任一开关即可开始接管。首次启用前会单独询问，请先保存工作；确认后工具会正常退出并重新启动极空间：通过临时的 `127.0.0.1` 调试端口，在极空间主进程中安装关闭与 Dock 控制逻辑，之后关闭并检查端口。开放期间，本机调试连接能访问目标进程数据。适配依赖客户端版本，失败时可能终止本次刚启动的极空间以避免遗留调试端口。退出超时会停止操作并提示，不能保证设置已生效。接管成功后，两个开关会在约一秒内直接生效；极空间退出后，下次需要重新接管。

## 数据与恢复

配置保存在本机：

- 偏好域：`io.github.syczk301.DockHush`
- 规则及备份：`~/Library/Application Support/DockHush/`
- 极空间诊断日志：`~/Library/Logs/DockHush/zspace.log`

Dock 操作先记录配置原件与事务。失败时还原该次操作前的文件；原先运行的应用会尝试重新打开。中断事务会在下次启动时检查；出现冲突时通过“查看详情”找到备份位置。提交问题时请勿附带未经检查的日志、备份、应用列表或个人路径。

退出 DockHush 会停止通用鼠标拦截，但已写入的 Dock 配置仍在；极空间运行时逻辑持续到极空间退出。卸载前请在列表恢复所需 Dock 状态，并退出极空间。旧版私人助手的配置不会迁入此公开版，避免影响现有安装；不要同时运行两个版本。

## 从源码构建

需要 macOS、Xcode Command Line Tools（`xcode-select --install`）、Python 3 和支持 macOS 13 SDK 的 Swift 编译器。

```sh
git clone https://github.com/syczk301/DockHush.git
cd DockHush
./scripts/check.sh
./scripts/build.sh
./scripts/package-dmg.sh
```

输出：`build/DockHush.app`、`dist/DockHush-0.1.0-universal.dmg` 及 SHA-256 文件。
构建脚本依次编译 arm64 与 x86_64，再合并为 Universal。`VERSION=0.1.0` 可指定版本。默认临时签名；维护者可通过 `SIGN_IDENTITY` 指定自己的 Developer ID，但公证需要单独完成。

项目结构：`Sources/` 原生应用与恢复引擎；`Resources/` 双语文本及可选运行时脚本；`scripts/` 构建、检查与打包；`Tests/` 隔离测试。

`./scripts/test-recovery.sh` 会在 `build/` 中创建并启动自建测试应用，验证正常隐藏/显示、失败还原、中断恢复及外部修改冲突；需要已登录的 macOS 图形会话。不会修改你安装的第三方应用。
